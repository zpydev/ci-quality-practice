# ci-quality-practice

A minimal, synthetic Node.js starter repository designed for practicing the construction of Continuous Integration (CI) quality workflows.

> **Note**: The source code in this repository was originally generated by Google Gemini in response to specific synthetic exercise requirements. It contains no human-authored code, proprietary snippets, or third-party dependencies.

## Target Environment

- **Node.js**: `24.7.0`
- **npm**: `11.6.2`

## Business Logic

The core logic is implemented in `src/calculate-total.js` as a pure function: `calculateTotalCents(items)`.

- **Input**: An array of line items, where each item must be a plain object containing:
  - `unitPriceCents`: Safe non-negative integer representing the unit price in cents.
  - `quantity`: Safe non-negative integer representing the quantity.
- **Output**: Total sum in cents as a safe integer.
- **Guarantees**:
  - Uses integer-based cents exclusively to avoid floating-point rounding errors.
  - Strictly rejects non-array inputs, null/missing items, floats, negative values, and non-safe integers.
  - Defensively guards against arithmetic overflow exceeding `Number.MAX_SAFE_INTEGER` at both the line subtotal and running total levels.
